# Segnalare una vulnerabilità

Non è consulenza legale. Questo file è per le persone che mantengono il repository. Il bot non apre issue e non scrive qui.

Se trovi un modo in cui il bot potrebbe divulgare dati, accettare un aggiornamento pericoloso o scrivere su GitHub, apri una issue con il template «Correzione a skill o modello». Non inserire dati personali, numeri, screenshot di schede o registri veri.

Indica il file, il comportamento atteso e quello osservato. Le skill in `skills/` richiedono la review del proprietario del repository (vedi `.github/CODEOWNERS`): la protezione del branch, se attiva, applica quel vincolo.

Non aprire una pull request che contiene dati di una persona per «dimostrare» il problema.
