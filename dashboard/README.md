# Dashboard

Non è consulenza legale. Apri `index.html` nel browser. Non serve un server: l'esempio finto è dentro la pagina ed è anche in `example-registro.json`.

Per un registro vero, usa «Carica registro JSON» e scegli un file locale, per esempio `registro.local.json` in questa cartella. Quel nome è in `.gitignore`. Non committare dati veri.

Lo schema è `docs/registro.md`. Le righe `inviata`, `in attesa` e `risposta` con scadenza passata sono evidenziate. La pagina non chiama servizi esterni e non include tracker.
